# ProChat 官网维护文档

ProChat 官网是一个基于 Astro 的静态网站，用于展示 ProChat 桌面聊天客户端、下载入口、隐私说明和常见问题。项目目标是保持页面简洁、可信、响应式，并适合部署到 Cloudflare Pages 或 Workers 静态托管环境。
